# Auction Platform - Backend

This is the **backend** of the Auction Platform built with the **MERN stack**.  
It handles user and seller authentication, product and auction management, bid tracking, and email notifications.

---

## Features

### User Functionalities
- User registration and login
- Profile management
- View bid history
- Place bids on items (traditional, reverse, sealed bid)
- Email notifications on bid updates

### Seller Functionalities
- Seller registration and login
- Product management (CRUD)
- Create and manage auctions
- Manage inventory
- Oversee bids and auctions

---

## Tech Stack
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose)  
- **Authentication:** JWT (JSON Web Tokens)  
- **Email Notifications:** SendGrid or Nodemailer  
- **Testing:** Postman
